# coding-interview-zh

程序员面试题库中文版 | 前端/后端/算法/数据库/网络 全中文面试题带答案

## 这是什么？

这是一个**全中文的程序员面试题库**，收录了 500+ 道常见面试题，覆盖前端、后端、算法、数据库、网络五大方向。

每道题都有：
- ✅ 清晰的中文题目描述
- ✅ 详细的参考答案
- ✅ 面试常见追问

## 为什么做这个？

### 痛点 1：面试题全是英文
你在 LeetCode、GitHub 上找面试题，大部分都是英文的。
查单词、翻译、理解，折腾半天，还是不知道答案是什么。

### 痛点 2：面试题零散不成体系
网上面试题东一个西一个，这个说考 JS 闭包，那个说考 TCP 三次握手。
你跟着学了半天，发现都是碎片，不知道重点是什么。

### 痛点 3：没有答案，不知道对错
很多面试题只有题目，没有答案。
你不知道自己想的对不对，面试的时候心里没底。

## 这个仓库有什么？

### 📌 前端方向（150 题）
- JavaScript 基础：闭包、原型链、this、事件循环
- ES6+：Promise、async/await、解构、箭头函数
- React：Hooks、状态管理、生命周期、性能优化
- CSS：布局、盒模型、Flex、Grid、响应式
- 浏览器：缓存、渲染、事件机制、跨域

### 📌 后端方向（150 题）
- Java：集合、JVM、并发、Spring
- Python：装饰器、生成器、GIL、异步
- Node.js：事件循环、Stream、中间件
- 设计模式：单例、工厂、观察者、策略
- 微服务：RPC、网关、熔断、分布式事务

### 📌 算法方向（100 题）
- 数组与字符串
- 链表与树
- 动态规划
- 二分查找
- 排序与搜索

### 📌 数据库方向（50 题）
- MySQL：索引、事务、锁、主从复制
- Redis：数据结构、持久化、缓存穿透、缓存雪崩
- MongoDB：文档模型、索引、聚合

### 📌 网络方向（50 题）
- TCP/IP：三次握手、四次挥手、滑动窗口
- HTTP/HTTPS：状态码、缓存、Cookie、Session
- 浏览器：输入 URL 到页面渲染全过程
- 安全：XSS、CSRF、SQL 注入

## 适合谁看？

- 准备秋招/春招的应届生
- 想跳槽换工作的在职程序员
- 想系统复习基础知识的开发者

## 怎么用？

1. 从你缺的方向开始
2. 先自己想答案，再对照参考答案
3. 把不会的题标记出来，重点复习
4. 面试前一周刷一遍高频题
